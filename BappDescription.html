ColorStrike integrates Burp Suite with AI clients using the Model Context Protocol (MCP), focused on a color-based triage workflow for manual penetration testing. Highlight requests in Burp Proxy History, then let the AI client analyze traffic by color group, identify attack vectors, and execute targeted payloads — a fork of PortSwigger's official MCP Server extension.

For more information about the protocol, visit modelcontextprotocol.io

Note: Any data sent to external tools via this extension is subject to their data processing policies.

Features

  • Color-based triage: only requests highlighted in Proxy History reach the AI client — three read levels from summary-only to fully untruncated, so context usage scales with how deep the analysis actually needs to go
  • Unified attack tool (SendRequest) with five injection modes — explicit targeting of body (JSON, form-urlencoded, or multipart/form-data), query, header, method, or a specific path segment, plus marker and automatic injection — and adaptive differential response analysis
  • Automatic HTTP/1.1 and HTTP/2 detection for every outgoing request, with real per-item baseline latency for calibrating time-based attacks
  • Access and filter proxy HTTP and WebSocket history with regex support
  • Generate and poll Burp Collaborator payloads for out-of-band testing (Professional only)
  • Create Repeater tabs and send requests to Intruder directly from an AI client
  • Built-in encoding utilities (URL, Base64) and proxy intercept control
  • Automatic Claude Desktop installation with a packaged stdio proxy server

Usage

  1. Navigate to the "MCP" tab and enable the MCP server.
  2. Highlight the requests you want the AI client to see directly in Burp Proxy History — that's the scope boundary this extension uses instead of a per-request approval prompt.
  3. Use the installer button to automatically configure Claude Desktop, or manually configure your MCP client to connect to http://127.0.0.1:9876 (SSE mode) or use the packaged stdio proxy server.
  4. Interact with Burp through your AI client using the available MCP tools.
